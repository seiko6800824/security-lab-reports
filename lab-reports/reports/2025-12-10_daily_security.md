# 日次セキュリティヘルスチェック レポート

- 日付: 2025-12-10
- 対象ホスト: seiko2 (Ubuntu Server, VirtualBox ゲスト)
- 実施者: seiko2

## 1. サーバ基礎情報の確認

- `uptime` で稼働時間と load average を確認。
  - 直近の load average: 0.18 / 0.25 / 0.11 と低く、CPU 負荷に異常なし。
- `who`, `last` でログインユーザーと履歴を確認。
  - ログイン中セッションはいずれも自分(seiko2)。不審なユーザーなし。
- `systemctl --failed` で failed サービスなし。

→ 基礎情報レベルでの異常は認められない。

## 2. journalctl / systemctl --failed の確認

- `journalctl -p err..alert` の結果:
  - `vmwgfx` に関するエラーが複数行。
    - VirtualBox 上で VMware 用グラフィックスドライバが動作していることによる警告であり、表示関連のみ。サーバのセキュリティや主要サービスの稼働には影響なし。
  - `PAM ... pam_lastlog.so` に関するエラーが複数行。
    - ログイン時に前回ログイン情報を表示するモジュール (pam_lastlog) が読み込めていない警告。
    - ログイン自体は正常に行えており、現時点では致命的な問題ではない。

→ いずれも「既知の無害な警告」と判断。状況は把握しつつ、現時点での対処は不要と判断。

## 3. 認証ログ (/var/log/auth.log) の確認

- `Failed password` / `FAILED LOGIN` / `authentication failure` を日付別に集計し、詳細を確認。
- 結果:
  - 2025-12-07:
    - `/dev/tty1` (コンソール) からのログイン失敗が 1 回。
    - `login` プロセスからのログ 2 行に分かれて記録されているが、いずれも自分(seiko2)のパスワード誤入力に起因するもの。外部IPや不明ユーザー名は無し。
  - 2025-12-10:
    - `sudo` 実行時のパスワード誤入力および `grep` 実行ログが数件。
    - すべて自分による操作であり、外部からの SSH ログイン失敗や辞書攻撃の痕跡は無し。
- `sshd` プロセスの失敗ログ (`grep sshd`) は 0 件であり、SSH に対する攻撃ログは確認されていない。

→ 現時点で、認証面での不審なアクセスは無し。
